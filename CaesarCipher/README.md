# Caesar Cipher in C#

A simple console application built in C# to encrypt and decrypt text using the Caesar Cipher algorithm. This project was developed as a practice exercise for programming logic and C# fundamentals.

## Features
* Encrypts plaintext provided by the user by shifting characters (default shift step: 4).
* Decrypts the ciphered text back to its original form.
* Demonstrates basic string manipulation and iteration in C#.

## Technologies Used
* C#
* .NET 10.0

## How to Run

1. Ensure you have the [.NET 10.0 SDK](https://dotnet.microsoft.com/) installed on your machine.
2. Open your terminal or command prompt.
3. Navigate to the project directory containing the `.csproj` file.
4. Run the following command:
   ```bash
   dotnet run
   ```
5. Type the text you want to encrypt when prompted.
