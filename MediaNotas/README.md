# Grade Calculator / Calculadora de Notas

## English

A simple C# console application that reads student grades and calculates their total and average.

### Features

- Asks how many grades will be entered (must be greater than zero).
- Accepts decimal grades from **0 to 10**, including both limits.
- Repeats the prompt when an entry is invalid.
- Displays the sum and average with two decimal places.

### Code structure

- **`Program.cs`** handles user input, validation, and output.
- **`MediaNotas.cs`** receives the grades and calculates the sum and average.

### How to run

With the .NET SDK installed, open a terminal in the project directory and run:

```bash
dotnet run
```

## Português (Brasil)

Uma aplicação simples de console em C# que lê notas de alunos e calcula sua soma e média.

### Funcionalidades

- Solicita a quantidade de notas (deve ser maior que zero).
- Aceita notas decimais de **0 a 10**, incluindo os limites.
- Solicita uma nova entrada quando o valor informado é inválido.
- Exibe a soma e a média com duas casas decimais.

### Organização do código

- **`Program.cs`** cuida da entrada de dados, validação e exibição dos resultados.
- **`MediaNotas.cs`** recebe as notas e calcula a soma e a média.

### Como executar

Com o SDK do .NET instalado, abra um terminal na pasta do projeto e execute:

```bash
dotnet run
```
